# Personal Portal · 公共版候选稿

一个可由 AI 维护的个人服务与链接导航模板。纯静态 HTML、CSS、JavaScript，无后端、无依赖安装、无构建步骤。

服务入口与分享资料分开管理，提供分类、跨空间搜索、浏览器地址栏快开、配置导入导出，以及跟随系统的深浅主题。分享卡片使用本地 SVG 线稿。

目前是本地候选稿，尚未公开发布；开源许可证将在正式发布前确定。

## 启动

在此目录运行：

```bash
python3 -m http.server 7576 --bind 127.0.0.1
```

打开 http://127.0.0.1:7576。Windows 如无 python3 命令，可使用 `py -3 -m http.server 7576 --bind 127.0.0.1`。需要已安装 Python 3，也可使用其他静态 HTTP 服务。

请通过 HTTP 打开，不要双击 index.html。示例卡片全部使用 example.com 虚构地址，不承诺指向实际内容。演示配置关闭了服务探测。

## macOS 登录自启动

```bash
./install-autostart.sh --port 7576
# 卸载时使用同一个项目目录中的脚本
./uninstall-autostart.sh
```

脚本自动识别自己的项目目录，可从其他工作目录调用。安装后立即启动，之后在当前用户登录时自动运行；仅监听本机。不需要 sudo。端口占用或已有安装时不会覆盖或停止其他服务。

详细的预览、换端口、迁移目录、日志和验证记录见 [AUTOSTART.md](AUTOSTART.md)。仅支持 macOS；其他系统继续使用手动启动方式。

## 换成自己的内容

只需维护四份文件：

| 文件 | 内容 |
| --- | --- |
| instance.json | 站点名称、分类主题、排序方式、浏览器存储键 |
| services.json | 服务入口、别名、备注 |
| shares.json | 分享资料、日期、分类、配图引用 |
| artwork.json | 分享卡片的专属 SVG 线稿 |

详细字段与保存规则见 [CONFIGURATION.md](CONFIGURATION.md)。图形规范见 [SHARE_CARD_STYLE.md](SHARE_CARD_STYLE.md)。不需要在通用脚本里重复填写数据。

新实例请设置独立 storage 键；已经使用的实例不要随意改键。页面编辑仅存在浏览器中，要分别导出服务、分享并写回文件才能进入仓库备份。文件版本升级不会自动覆盖个人收藏。配置冲突需先导出再合并。

## 让 AI 帮你维护

可以把下面的任务交给能读取本地项目的 AI：

> 请先读取项目 AGENTS.md、CONFIGURATION.md 和 skills/portal-maintainer/SKILL.md，把我提供的链接加入合适空间，保留已有内容；新增分享时按 SHARE_CARD_STYLE.md 绘制专属线稿。检查浏览器是否有未导出的编辑，完成配置检查及实际页面验证。

随后提供标题、完整 URL、用途、分类（可选）、日期（未知留空）及别名。

Skill 随仓库提供，不自动安装到任何 AI 客户端。支持 Skills 的客户端可按自身方式安装 `skills/portal-maintainer`；其他 AI 直接读取文档即可。

## 搜索与快开

- 顶部搜索服务与分享；空间内搜索只筛选当前空间。
- `⌘K` / `Ctrl+K` 或 `/` 聚焦全局搜索。
- 浏览器自定义搜索引擎关键字：`go`；地址：`http://127.0.0.1:7576/?q=%s`。
- `?q=` 唯一匹配会倒计时打开，可取消；手动输入不自动倒计时。
- 分享在新标签页打开；非网页服务复制连接串。

## 框架更新与私有实例

`framework.json` 列出通用文件。更新时仅审查并引入这些文件，保留四份实例 JSON 和本机启动配置。私有实例可以完整备份某个框架版本，换电脑时直接恢复。

含真实内容的实例应保存在私有仓；不要把个人配置提交回这个演示模板。静态站点的配置可被站点访问者读取；是否使用私有 Git 仓并不决定网站是否私密。本模板不提供登录权限控制、云同步或服务安装。

## 开发检查

```bash
node --test config.test.cjs
python3 autostart.test.py
node check-public.cjs
```

Node 仅用于检查，不是运行时依赖。`check-public.cjs` 检查当前候选稿仅含示例地址和允许的发布文件；它不是通用的秘密扫描器。公开发布前仍需人工审查文档、截图与全部待提交文件。

视觉检查要求：桌面 1440×1000、手机 390×844，分别检查深浅主题。首次发布前选择许可证、确认仓库名称并建立全新 Git 历史；本候选稿未携带任何私有仓历史。
