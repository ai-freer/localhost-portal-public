# 导航内容维护

先定位用户指定的项目根目录，读取其中的 AGENTS.md、CONFIGURATION.md；涉及分享配图再读 SHARE_CARD_STYLE.md。本 Skill 随项目分发，文档以目标项目为准，不以 Skill 安装目录推断项目路径。

- 服务入口进入 services.json；报告、资料、分享页面进入 shares.json。用户指定的空间优先，不为同一请求自动向两个空间重复添加。
- 使用用户提供的完整 URL、名称、分类、日期和别名。缺少日期留空；不得编造服务身份、正文事实或访问地址。仅在任务需要理解正文且有访问权限时读取目标内容。
- 按 URL 标准化结果查重，但保留原始完整 URL。更新既有项保留 ID、扩展字段及无关内容。新增分享使用独立 ID 和 artwork 标识；不要用 URL 尾段作为绘图键。
- 分类顺序与主题配置遵循 CONFIGURATION.md；优先复用已有分类。新增分类补齐图标、tone 和排序设置。
- 新分享在 artwork.json 中绘制与主题相符的专属静态 SVG 线稿。遵循现有卡片密度、右上中等尺寸与低饱和配色，不修改全局样式。没有配图要求的纯文字修订保留原图。
- 浏览器配置优先于文件。文件修改不会立即替换已保存的收藏；先核对是否存在未导出的编辑，必要时导出并按 ID/URL 合并。不要清空存储、提高 version 或自动补回已删除条目来强行同步。
- 不把实例内容写入 index.html 或通用 JS。不修改服务监听、系统启动或公开部署设置。

完成后运行项目配置测试；实际检查搜索、分类、目标地址、编辑保存。配图变化需截图检查桌面深浅主题和手机。报告修改文件、保留情况、实际验证及未完成项。没有浏览器能力时明确说明视觉检查尚未完成。
